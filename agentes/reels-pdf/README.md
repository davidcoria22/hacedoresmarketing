# Agente de Reels y PDF

Responde a los comentarios de un reel de Instagram cuando alguien escribe la palabra clave, le pide que siga la cuenta y, después de confirmar, le envía el enlace del PDF.

**Estado:** en configuración. Todavía no envía nada: primero hay que definir la palabra clave, el reel y el PDF (ver `config.md`), y la app de Meta necesita Acceso Avanzado para escribirle a personas que no tienen rol en la app.

Archivos:
- `instrucciones.md`: flujo paso a paso y reglas.
- `config.md`: palabra clave, reel, enlace del PDF y modo de operación.
- `registro.csv`: una línea por cada persona atendida.
